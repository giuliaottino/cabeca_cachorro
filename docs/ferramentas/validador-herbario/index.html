Validador de planilhas de herbário.

Envie uma planilha padrão INPA/BRAHMS. O sistema reproduz a planilha no navegador, marca erros e alertas diretamente nas células, mostra os pontos de coleta no mapa e gera uma cópia .xlsx anotada para correção.
